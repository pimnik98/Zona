# Zona GeoIP Firewall

Скрипты для комплексной защиты сервера Ubuntu 20.04 LTS, массового сканирования портов и несанкционированного доступа из-за рубежа. (Содержимое папки распаковать в /opt/zona/)

## 📋 Описание архитектуры
Система реализует подход **"Полной невидимости" (Offline режим)**. Все входящие пакеты со всего мира, кроме доверенных регионов, поисковых систем и платежных шлюзов, молча отбрасываются брандмауэром ядра (`iptables DROP`), не нагружая процессор и сетевой стек.

## 🛠 Компоненты системы
1. **`update_geoip.sh`** — Главный скрипт автоматизации. Объединяет локальные списки разрешенных стран, автоматически загружает актуальные пулы роботов Google/Yandex и белые списки платежных систем, после чего атомарно обновляет таблицы `ipset`.
2. **`checkip.sh`** — Утилита командной строки для быстрой валидации любого IP-адреса на предмет наличия доступа к серверу.

## 📂 Структура каталогов
```text
/opt/zona/
├── update_geoip.sh       # Скрипт генерации белых списков
├── checkip.sh            # Утилита проверки IP
├── ru.zone               # Локальная база подсетей России
├── by.zone               # Локальная база подсетей Беларуси
├── ua.zone               # Локальная база подсетей Украины
├── nl.zone               # Локальная база подсетей Нидерландов
├── fi.zone               # Локальная база подсетей Финляндии
└── other.zone            # Универсальные IP для которых нужен доступ (Вписан Google, Yandex, WebMoney, YooKassa)
```

## 🚀 Настройка и развертывание

### 1. Создание системных ссылок
Для глобального вызова утилиты проверки создайте символическую ссылку в системном `PATH`:
```bash
sudo ln -s /opt/zona/checkip.sh /usr/local/bin/checkip
sudo chmod +x /opt/zona/*.sh
```

### 2. Настройка автозапуска списков ipset
В Ubuntu 20.04 брандмауэр iptables восстанавливается раньше, чем успевают отработать скрипты. Если iptables попытается включить защиту, а списка allowed_countries еще нет в памяти, сервер выдаст ошибку и останется открытым.
Чтобы этого не произошло, мы заставим систему создавать пустой каркас списка при старте:
```bash
sudo nano /etc/rc.local
```
Добавьте строку:
```bash
#!/bin/bash
# Создаем пустой список, чтобы iptables не ругался при старте
ipset create allowed_countries hash:net maxelem 500000 2>/dev/null

# Сразу же запускаем ваш скрипт, чтобы наполнить список IP-адресами из файлов
/opt/zona/update_geoip.sh

exit 0
```
Незабудьте сделать файл исполняемым:
```bash
sudo chmod +x /etc/rc.local
```

### 3. Обеспечение персистентности (Автозапуск при перезагрузке)
Чтобы при перезагрузке сервера структуры `ipset` не пропадали из оперативной памяти, добавьте инициализацию в `/etc/rc.local`:
```bash
#!/bin/bash
ipset create allowed_countries hash:net maxelem 500000 2>/dev/null
/opt/zona/update_geoip.sh
exit 0
```
*Убедитесь, что правила persistent-брандмауэра сохранены: `sudo netfilter-persistent save`.*

## 🔍 Использование утилиты проверки
Проверить, имеет ли конкретный IP доступ к серверу (утилита автоматически проверяет вхождение IP во все 22000+ подсетей):
```bash
checkip 8.8.8.8
```
